# Discovery Method Library

A reference catalogue of named discovery activities, organized by what
you're trying to learn and how much time you have. Pairs with the
Discovery skill, use that skill to scope the opportunity and identify
the riskiest assumption, then come here to pick the specific activity
to run.

## How to choose a method

**1. Where are you in discovery?**
- Just starting, need to define the problem → *Problem Understanding* or *Problem Framing* methods
- Have a problem hypothesis, need to validate it → *Problem Validation* methods
- Problem validated, need solution ideas → *Ideation* methods
- Have solution ideas, need to test them → *Solution Validation* methods
- Solution validated, need to plan delivery → *Decision & Delivery Planning* methods
- Team alignment, retro, or kickoff → *Team & Facilitation* methods

**2. How much time do you have?**
- Under 30 minutes → quick tools (Secret Vote, Theme Sort, Who/What/When, T-Bar)
- 30-60 minutes → single methods (Five Whys, Assumption Map, Priority Map...)
- Half a day → recipes (Idea Storm, Get Unstuck, Project Kick-Off)
- Full day or more → extended recipes (Design Dash, Team Time)

## Recipes (multi-hour sequences)

| Recipe | Duration | Best for | Sequence |
|---|---|---|---|
| **Design Dash** | 2 days | Blank page to testable prototype | Journey Map → Idea Storm → Priority Map → Storyboard → Prototype → Test |
| **Idea Storm** | 3-4 hrs | Wide idea generation then refinement | How Might We → Mind Map → Idea Eight → T-Bar → Rose/Thorn/Bud |
| **Get Unstuck** | 3-4 hrs | Diagnosing and unblocking | Sailboat → Five Whys → How Might We → Reverse Brainstorm → Rose/Thorn/Bud |
| **Project Kick-Off** | 4 hrs | Aligning before starting | Premortem → Problem Statement → Assumption Collecting → Assumption Map → Hypothesis Statement |
| **Team Time** | 3-4 hrs | New team alignment | Newspaper Headline → Sailboat → Roles & Responsibilities → Skills Market → Stakeholder Map |
| **Retrospective** | 2 hrs | Reflect and improve | Mad/Sad/Glad (or Start/Stop/Continue, or Rose/Thorn/Bud) → Democratic Discussion → Who/What/When |

## Method categories (for deeper reference)

- **Problem Understanding**: Five Whys, Customer Interview Synthesis, Journey Map, Empathy Map, Context Map / Service Blueprint, Problem Tree Analysis, Quantify/Qualify the Problem
- **Problem Framing**: Problem Statement, How Might We, Hypothesis Statement, Assumption Map
- **Ideation**: Idea Eight, Mind Map, T-Bar Format, Storyboard, Assumption Reversal
- **Solution Validation**: Willingness-to-Pay Test, Conjoint Analysis, Fake Door Test, Proposition Testing, Prototype Usability Testing, Guerrilla Testing, Business Model Road Test, Concierge Test, Card Sorting, Onboarding A/B Test
- **Decision & Delivery Planning**: Impact/Effort Map, Priority Map, Story Mapping, Premortem, SWOT Analysis, Rose/Thorn/Bud
- **Team & Facilitation**: OKRs, Newspaper Headline, Sailboat, Retrospective formats, Roles & Responsibilities, Stakeholder Map

## How to run any method

1. Confirm the primary question the method needs to answer (ties back to the Discovery skill's riskiest-assumption framing)
2. Look up or recall the method's standard steps
3. If facilitating live: set purpose, timing, and steps up front for the group
4. If working solo/async: adapt the steps for individual use
5. Capture the output clearly and carry it into the next discovery step (validation, sizing, or prototyping) rather than letting it sit unused
