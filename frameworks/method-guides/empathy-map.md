# Empathy Map

*Understand · 1 hr · Discovery, Team Building, Understanding the problem*

## Purpose

Build empathy by exploring what the user is saying, thinking, doing, and feeling. Includes their jobs, pains, and gains.

## When to Use

- When designing for a specific user segment
- To build empathy quickly in a workshop
- Before prototyping personas or testing assumptions

## How to Run

**Duration:** 1 hour

**Materials needed:** Whiteboard or digital workspace, sticky notes

**Steps:**

1. Draw a template with sections: **Says, Thinks, Does, Feels**, plus **Jobs, Pains, Gains**.
2. Define the user's goal in the middle.
3. Ask participants to capture what they believe about the user in each category.
4. Share, group, and discuss.
5. Use an Assumption Map afterwards to decide what needs validation.

## Tips

- Don't just focus on rational jobs - emotional context matters
- Use real user research if available to validate assumptions
- This is a hypothesis tool - test your empathy map with actual users
