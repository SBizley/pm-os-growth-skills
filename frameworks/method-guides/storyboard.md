# Storyboard

*Ideas · 1-2 hrs · Discovery, Ideation*

## Purpose

Visualise how an idea works in practice by sketching it as a sequence of user interactions. This helps uncover gaps and make the idea shareable.

## When to Use

- When you need to communicate a concept clearly
- To test the flow of an idea before prototyping
- As a bridge between ideation and evaluation

## How to Run

**Duration:** 1-2 hours

**Materials needed:** Paper, markers

**Steps:**

1. Define the key moments of the idea or user journey (e.g., 4-8 steps).
2. Draw the first frame (scene) - either on paper or digitally.
3. Continue sketching frames for each step, adding simple drawings and short captions.
4. When the sequence is complete, review as a group. Ask:
    - Does it make sense?
    - What could be improved?
    - What's missing or unnecessary?
5. Refine the storyboard. Optionally, evaluate using Rose, Thorn, Bud or Idea Beetle.

## Tips

- Doesn't need to be artistic - stick figures work fine
- Use this as input for Design Dash or prototyping
- Focus on the user's experience, not technical implementation
