# Conjoint Analysis

*Evaluate · 2 days · Validation Solution*

# **Purpose**

Quantitatively discover which feature-price trade-offs users prefer.

# **When to Use**

- When designing tiered pricing or bundles
- To decide what to include in an MVP

# **How to Run**

**Duration:** 2–3 days

1. Pick ≤ 6 attributes (e.g. speed, analytics, price).
2. Generate 6–8 feature bundles.
3. Ask 100 + users to choose repeatedly.
4. Analyse relative importance & utility scores.

# **Example**

Merchants value “instant payout” 2× more than “custom analytics” and will pay +£10/month.

# **Tips**

- Keep choices simple; avoid fatigue.
- Use tools like Conjoint.ly or Qualtrics.
