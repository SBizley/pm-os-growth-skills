# Prototype Usability Testing

*Evaluate · 2 days · Validation Solution*

# **Purpose**

Validate whether users can complete key tasks using a prototype.

# **When to Use**

- Before build hand-off
- To refine IA and flows

# **How to Run**

**Duration:** 1 day

1. Define 3–5 core tasks.
2. Recruit 5–8 target users.
3. Observe interactions, capture success and errors.
4. Synthesise themes and priority fixes.

# **Example**

6 merchants: 83 % completed flow successfully; terminology change resolved confusion.

**Tips**

- Record sessions for evidence.
