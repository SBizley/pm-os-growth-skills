# Design Dash

*Recipe · 2 days · Discovery, Ideation, Prioritisation*

## Purpose

Go from a blank page to a testable prototype in just two days. Compresses discovery, ideation, and prototyping into a focused sprint.

## When to Use

- When speed is critical
- To quickly validate new ideas with users
- As an alternative to a full week-long design sprint

## How to Run

**Duration:** 2 days

**Materials needed:** Whiteboard, sticky notes, prototyping tools (paper, Figma, etc.), access to test users

**Day 1:**

1. **Journey Map (1-2 hrs)** - Map the customer journey to find opportunities.
2. **Idea Storm (2-3 hrs)** - Generate and refine solutions.
3. **Priority Map (1 hr)** - Rank ideas by criteria (impact vs effort, cost vs value, etc.).
4. **Storyboard (1-2 hrs)** - Flesh out the winning idea as a sequence of steps.

**Day 2:**

1. **Build prototype (4-5 hrs)** - Low-fidelity is fine. Focus on testing the core hypothesis.
2. **Test with users (2-3 hrs)** - Run 3-5 user tests and gather feedback.

## Tips

- Timebox ruthlessly - momentum matters more than polish
- Use the prototype test as input for your next iteration cycle
- Keep the team small (5-7 people max) for agility

## Outcome

A testable prototype built from user insight, not guesswork.
