# Theme Sort

*Techniques · 10 min · Alignment*

## Purpose

Make sense of large volumes of ideas, insights, or problems by clustering them into themes. Helps the group spot patterns and organise thinking.

## When to Use

- After brainstorming or feedback sessions
- When sticky notes are piling up and need structure
- To find patterns in qualitative data

## How to Run

**Duration:** 10 minutes

**Materials needed:** Sticky notes, wall or digital workspace

**Steps:**

1. Clear a large space for notes.
2. Place notes one at a time, reading them aloud.
3. Each time, ask: "Is this similar to something already here?"
    - If yes → place near related notes
    - If identical → stack behind the original
    - If not → create a new cluster
4. Once everything is grouped, give each cluster a theme title.
5. Review outliers to decide if they belong anywhere.

## Tips

- Easier if you theme sort as you go instead of leaving it all until the end
- Use Priority Map or Secret Vote to decide which themes matter most
- Involves the whole group in clustering for shared understanding
