# Onboarding A/B Test

# **Purpose**

Identify which onboarding flow, message, or sequence drives higher activation and early engagement.

# **When to Use**

- When activation or time-to-first-value is low
- To test education, step reduction, or motivation variants

# **How to Run**

**Duration:** 3–14 days

**Materials:** Experiment platform (Amplitude, Optimizely, LaunchDarkly, etc.)

# **Steps**

1. Define **success metric** (e.g., activation rate, setup completion, time-to-first-transaction).
2. Create at least two onboarding flows (A/B or multivariate).
    - Variant A → current experience
    - Variant B → new steps, different copy, nudges, or tooltips
3. Run until statistically significant (> 95 % confidence or stable over n ≥ 200).
4. Analyse uplift in target metric and secondary retention metrics.

# **Example**

Shortened onboarding (4 steps → 2) increased first-payment rate by +12 %.

**Tips**

- Keep one major variable per test (steps vs copy vs UI).
- Run follow-ups to isolate education vs friction effects.
