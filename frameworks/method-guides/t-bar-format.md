# T-Bar Format

*Techniques · 30 min · Ideation*

## Purpose

Turn rough ideas into something that explains itself - combining a sketch, a name, and a short description. Creates consistency so ideas can be compared side by side.

## When to Use

- After idea generation
- Before evaluation or decision-making
- To create clear, shareable idea documentation

## How to Run

**Duration:** 30 minutes

**Materials needed:** Paper, markers

**Steps:**

1. Ask each person to draw a large "T" on their page.
2. In the top bar → give the idea a title.
3. On the left side → draw a quick sketch of the idea.
4. On the right side → write a short description or bullet points.
5. Share T-Bars with the group.
6. Use Secret Vote or Priority Map to narrow down.

## Tips

- The sketch doesn't need to be artistic - clarity over beauty
- Works especially well before tactics like Impact/Effort Map
- Creates a consistent format for comparing multiple ideas
